# 混合网格的保量张量重映射

两张合成目标格网给出质检部门和定位部门各自认可的坐标，双方独立对账。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

`x`、`y` 给源格网轴边界，格点身份采用行、列。每块瓦片为矩形索引窗，`owners` 确定实际拥有者。字段 `amount` 是有效源格的完整格面积所含总量，`intensity` 是源格均匀强度。裁剪窗以及目标框按 x0、x1、y0、y1。区域元素左闭右开。
`priority` 较大者优先。目标有效覆盖率的分母是目标在公共裁剪窗内、扣除同组优先占有部分后的面积。空区域不产生覆盖率。各组的有效目标量加上未被这组目标覆盖的有效源量，应等于原有效源量，裁剪窗外的量计入未覆盖。质量判断需覆盖率达到配置值，有效区域的重映射数值容差 1e-9。已经关闭的来源版本不得被修改。

## 读取资料

使用 Python 3.11。首次创建本地环境时安装锁定依赖。只读查看显示原始字段和张量尺寸。

```sh
python -m pip install -r requirements.txt
python caseio.py data/capture.json
python -m unittest discover -s tests -v
```

现有检查核对采集格式和所附数据的结构。
